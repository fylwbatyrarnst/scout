# عشيرة جوالة كلية العلوم - جامعة عين شمس (نسخة JSONBin السحابية)

مشروع الموقع الرسمي لعشيرة جوالة كلية العلوم - جامعة عين شمس بهوية كحلي/أسود وذهبي مع لوحة تحكم (Admin Dashboard) ومزامنة سحابية عبر **JSONBin.io** بدون أي تعقيدات أو مشاكل تحقق ثنائي في حساب Firebase.

## خطوات الإعداد
1. سجل حساباً مجانياً على [JSONBin.io](https://jsonbin.io) (ممكن بحساب GitHub أو إيميل وباسورد).
2. أنشئ Bin جديد وانسخ **Bin ID** و **Access Key** (أو Master Key).
3. أنشئ ملف `.env` بناءً على `.env.example` وضع فيه القيم، وأضف نفس المتغيرات في **Vercel -> Environment Variables**.

## تشغيل المشروع محلياً
```bash
npm install
npm run dev
```
